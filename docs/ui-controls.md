# 사이트 공통 입력 UI

2026-11-18 (한국 시간). Windows/브라우저 기본 선택 목록과 앱의 둥근 입력칸이 서로 달라 보이는 문제를 해결한다. 주간 디자인뿐 아니라 예매자 명단, 문자 명단, 이미지 변환, 정산서, 원본대조필, Instagram 게시·관리·달력에 공통 컴포넌트를 적용한다.

## 구성과 동작

- `scripts/shared-controls.css`: 기존 라이트/다크 디자인 토큰을 사용한다. 입력칸·버튼은 8px, 목록은 12px, 선택 대화상자는 16px 모서리를 사용하며 보더·보라색 선택 표시·그림자·키보드 포커스를 맞춘다. 체크박스·라디오·슬라이더·파일 선택 버튼과 주간 편집기의 화면 색도 같은 토큰을 사용한다.
- 펼친 드롭다운까지 `appearance: base-select`로 스타일링한다. 지원하지 않는 엔진에는 앱 listbox를 표시한다. fallback은 원래 `select` 값과 `input`/`change` 이벤트를 유지하며 방향키/Home/End/PageUp/PageDown, 문자 검색, Enter 선택, Escape 취소, Tab 이동, 비활성 옵션과 optgroup을 처리한다. 모달 안에서는 모달의 상단 팝업으로 표시하며 기존 옵션과 팝업 옵션이 접근성 트리에 중복 노출되지 않도록 한다. 동적으로 만든 엑셀 열 선택 목록에도 적용된다.
- `scripts/shared-calendar.js`: 날짜·월·시간·예약 날짜/시간을 공통 대화상자로 선택한다. 날짜/시간 필드는 직접 입력도 가능하며 선택 버튼으로 앱 선택창을 연다. 선택 완료 전에는 원래 값을 바꾸지 않는다. 선택한 값은 기존 이벤트로 전달하며 예약의 한국 시간과 30일 범위, 입력의 min/max/required 제약을 유지한다. 선택형 회차 시간은 비울 수 있다. 저장된 예약을 불러오는 등 코드에서 값을 설정해도 표시를 동기화한다.
- 색상은 앱 대화상자의 브랜드 색상, HEX 코드, RGB 슬라이더로 선택한다. 적용해야 값이 변경되며 취소/Escape는 원래 값을 유지한다. 잘못된 HEX 값은 적용할 수 없다.
- `EnticketUI.alert/confirm/prompt`는 앱 공통 안내·확인·파일 암호 대화상자다. 확인이 필요한 기존 작업은 `await`로 사용자 선택을 기다리며 취소가 기본 초점이다. Escape/닫기/로그인 상태 변경은 확인으로 처리하지 않는다. 메시지는 `textContent`로 표시하며 파일 암호는 password 입력을 사용하고 닫을 때 지운다. 브라우저의 페이지 이탈 경고와 운영체제 파일 탐색기는 브라우저/OS 기능으로 유지한다.

공통 JS/CSS는 `scripts/public_assets.py`가 공개 HTML에 포함한다. 새 외부 라이브러리를 추가하지 않고, CSP 스크립트 해시는 실제 빌드에 맞춰 생성한다. 소스 디렉터리를 공개 자산 경로에 추가하지 않는다. 인증 정책·서버 API·게시 확인 조건·정산서 생성 형식은 변경하지 않는다.

## 검증

서버 52개 테스트 통과. 아래 9개 브라우저 검사도 통과했으며 계정·Instagram·Drive 요청은 모의 응답을 사용했다.

- `controls-browser.py`: 기본 선택 목록과 fallback(미지원 조건을 모의로 설정), 동적 엑셀 열 선택, 모달 안 목록, 키보드 이동/취소, 날짜/시간 적용·비우기, 색상 적용/취소/검증, 초안 변경의 명시적 확인, 암호 입력 취소, 문자 그대로 표시, 다크 모드, 320/390px 표시.
- `studio-browser.py`, `weekly-browser.py`: 캔버스 조작과 저장/복원, 레이어/페이지 순서, SVG/JPG, 달력 드래그, 가져오기, 공연 수정창, 이전 템플릿, 8개 공연/10장, 게시 준비 고정·내용 확인·로그아웃.
- `instagram-browser.py`, `instagram-scheduling-browser.py`, `instagram-management-browser.py`: 게시 준비·내용 확인·초기화·예약 시간/변경/취소·게시물 목록·오류/재시도·모바일.
- `cloud-browser.py`: 허용 계정·거절·만료·네트워크/서버 오류와 재로그인 안내, Drive 업로드 모의 흐름.
- `browser-smoke.py`: 로컬 5개 도구, XLSX/TXT/JPEG/PDF 출력, 정산서 1,406개 셀의 서식·수식 유지. 서버 접근 없이 실행.
- `security-browser.py`: 악성 XLSX 문자열, CSP, 외부 라이브러리 SRI.

실제 계정의 게시·예약·공연 일정 변경은 검증 목적으로 실행하지 않았다. 실제 다른 브라우저 엔진 검사는 별도이며 fallback 동작은 Chromium에서 지원 검사 결과를 모의로 바꿔 확인했다.
